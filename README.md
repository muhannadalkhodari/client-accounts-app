# حسابات العملاء (Client Accounts App)

تطبيق PWA لإدارة حسابات عملاء المكتب المالية (قبض/دفع)، Frontend بالكامل مع Firebase كطبقة بيانات.

## التشغيل محلياً
```
npm install
cp .env.example .env   # ثم املأ القيم من إعدادات مشروع Firebase
npm run dev
```

## البناء للإنتاج
```
npm run build
```

هذا المشروع قيد الإنشاء خطوة بخطوة. راجع سجل المحادثة لمعرفة الخطوة الحالية.
